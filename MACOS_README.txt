AnalyticsBot — запуск на macOS

1. Распакуйте архив и перенесите AnalyticsBot.app в «Программы» своего пользователя или /Applications.
2. Откройте AnalyticsBot.app и пройдите мастер: подключите Telegram, выберите JSON-ключ Google и укажите канал с таблицей.
3. Предоставьте показанному email сервисного аккаунта права редактора в таблице.
4. После проверки подключений нажмите «Завершить». Мониторинг запустится автоматически.

Python на компьютере получателя не нужен. Используйте сборку под процессор вашего Mac: arm64 для Apple Silicon (M1 и новее), x86_64 для Intel. Минимальная версия macOS зависит от версии Qt/PySide6, использованной при сборке.

Настройки, SQLite, Telegram-сессия и Google-ключ находятся вне приложения:
~/Library/Application Support/AnalyticsBot
В Finder выберите «Переход → Переход к папке» и вставьте этот путь. Эта папка содержит секреты: не включайте её в архив для другого пользователя. Обновление .app не сбрасывает настройки. Для переноса существующей установки сначала полностью завершите приложение, затем скопируйте содержимое прежней user_data в эту папку.

Закрытие окна оставляет приложение работать через значок в строке меню macOS. Открыть окно или полностью завершить работу можно через меню значка. Если значок недоступен, закрытие окна завершает приложение. На спящем или выключенном Mac сбор не выполняется; после запуска задания восстанавливаются, как и на Windows.

Для автозапуска добавьте AnalyticsBot в «Системные настройки → Основные → Объекты входа». Встроенная настройка автозапуска Windows на Mac недоступна.

Локальная сборка не имеет подписи Developer ID и нотариального заверения Apple. При блокировке доверенной копии используйте штатный раздел «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Не отключайте защиту macOS целиком. Для публичного распространения разработчику нужны подпись Developer ID и нотариальное заверение.
