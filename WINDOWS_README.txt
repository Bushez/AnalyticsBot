AnalyticsBot — запуск в Windows

1. Скопируйте всю папку AnalyticsBot в доступное для записи место, например в Документы.
2. Запустите AnalyticsBot.exe.
3. В мастере пройдите шаг Telegram: получите API ID и API hash по ссылке в окне и войдите по коду или QR. Пароль 2FA потребуется, только если он включён.
4. На шаге Google выберите JSON-ключ сервисного аккаунта. Мастер покажет email: предоставьте ему права редактора в вашей таблице.
5. На последнем шаге укажите канал и таблицу, загрузите список вкладок, выберите нужную и проверьте подключения. Нажмите Завершить.
6. Мониторинг запустится автоматически. При следующих открытиях приложения настройка повторно не нужна. Закрытие главного окна сворачивает его в трей; полный выход — в меню значка.

Мастер сохраняет прогресс. Можно закрыть приложение и продолжить настройку позже. Коды входа и пароль 2FA не сохраняются. Аккаунты и ключи меняются в Настройках через отдельные окна; интервалы сбора находятся в разделе Дополнительные настройки.

Все пользовательские данные хранятся в папке user_data рядом с программой. Для переноса своей установки скопируйте всю папку после завершения работы. Чтобы передать новую копию другому человеку без своих ключей и сессии, исключите папку user_data. Храните эту папку в секрете.

CLI и GUI используют разные файлы данных и не синхронизируют изменения. Для перехода с предыдущей установки GUI полностью завершите её и скопируйте папку user_data рядом с новой программой.

Можно включить открытие приложения при входе в Windows. Мониторинг всегда запускается автоматически после завершённой настройки. При переносе папки заново сохраните настройку автозапуска.
