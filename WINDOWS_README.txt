AnalyticsBot — запуск в Windows

1. Скопируйте всю папку AnalyticsBot в доступное для записи место, например в Документы.
2. Запустите AnalyticsBot.exe.
3. Откройте Настройки, введите API ID и API hash от my.telegram.org и войдите в Telegram по коду или QR-коду.
4. Выберите JSON-ключ сервисного аккаунта Google. Откройте вашу Google-таблицу для email этого аккаунта с правом редактора.
5. На странице Каналы добавьте Telegram-канал, ссылку на таблицу, название вкладки и при необходимости настройте столбцы.
6. На главной странице нажмите Запустить. Для закрытия без остановки сверните окно в трей. Для полного выхода используйте меню значка в трее.

Все пользовательские данные хранятся в папке user_data рядом с программой. Для переноса своей установки скопируйте всю папку после завершения работы. Чтобы передать новую копию другому человеку без своих ключей и сессии, исключите папку user_data. Храните эту папку в секрете.

Если вы переходите с предыдущей версии CLI, остановите её и используйте кнопку импорта на странице Настройки. Выберите папку проекта, в которой находятся config.yaml и .env. Импорт возможен только в пустую папку данных GUI. После импорта не запускайте старый CLI одновременно с GUI: их базы независимы, а сессия Telegram скопирована.

Можно включить автозапуск приложения при входе в Windows и отдельно — автоматический запуск сбора. При переносе папки заново включите автозапуск.
